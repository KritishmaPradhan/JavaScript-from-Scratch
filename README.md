# Tic Tac Toe Game

A fun and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.
This project brings the classic game to life with smooth animations, background theme switching, and a joyful confetti effect when a winner is announced! 🎉
---

##✨ Features

**Classic Gameplay:** Play the traditional 3x3 Tic Tac Toe with a friend.

**Theme Changer:** Click the theme button on the top-left corner to switch between cool background themes.

**Confetti Celebration:** When a player wins, enjoy a burst of confetti for the victory moment!

**Simple & Clean UI:** Sleek layout with CSS transitions and smooth animations.
---

##🛠️ Tech Stack

-**HTML5** – Structure of the game

- **CSS3** – Styling, layout, and animations

- **JavaScript** – Game logic, interactivity, and effects

##🕹️ How to Play

Open the link above in your browser.

Players take turns clicking the grid cells to mark X or O.

The game checks automatically for a win or draw.

When a player wins, a confetti celebration appears! 🎉

You can change the background theme anytime using the theme button on the top-left corner.
